처음 사용하는 방법

  1. 이 HTML 파일을 Edge 또는 Chrome에서 여세요. 인터넷과 별도 설치는 필요하지 않습니다.
  2. DAT/OPT와 Native/Text/Images 폴더를 함께 포함하는 패키지 루트 폴더를 선택하세요. 자동으로 검사를 시작합니다.
  3. REVIEW / INCOMPLETE이면 ‘로드 파일 설정’에서 인코딩, 구분자, 문서 ID와 경로 필드를 확인한 뒤 다시 검사하세요.
  4. 결과를 필터링하고 CSV 또는 JSON 보고서를 저장하세요. 원본 파일은 직접 수정되지 않습니다.

판정 읽기

PASS

선택 범위 검사가 완료됐고 보고할 오류·경고가 없습니다. 고객사별 납품 규격 인증을 의미하지 않습니다.

REVIEW

전체 검사는 끝났지만 인코딩 추정, 미참조 파일, 대소문자 차이 등 확인할 항목이 있습니다.

FAIL

경로 누락, 중복 문서, OPT 불일치 등 오류를 발견했습니다.

INCOMPLETE

해석 모호성, 읽기 실패, 자료 변경 또는 자원 제한으로 검사가 완료되지 않았습니다. 오류도 함께 있을 수 있습니다.

지원하는 규격

Concordance ASCII 20 / þ (254), ^value^|^value^, CSV, TSV, pipe, caret. 한 줄에 하나의 OPT 이미지 레코드, 7개 필드, Y 문서 시작, 시작 레코드의 페이지 수를 지원합니다. 공백 또는 N은 문서 계속입니다.

인코딩은 UTF-8, UTF-16LE/BE, Windows-1252를 지원하며, 다른 문자 집합은 설정에서 명시적으로 선택할 수 있습니다. BOM 없는 비 UTF-8 추정은 경고로 남깁니다. 따옴표와 줄바꿈을 포함한 필드도 나눠 읽으며 보존합니다.

경로와 매핑

기본 경로 기준은 패키지 루트와 로드 파일 위치입니다. 둘이 다른 실제 파일을 가리키면 모호성 오류가 납니다. Windows의 \ 구분자를 지원하고, 같은 파일명만으로 임의 연결하지 않습니다.

X:\Export001\Native\a.msg 같은 경로는 해당 소스의 ‘제거할 경로 접두사’에 X:\Export001\을 지정하면 선택한 루트를 기준으로 대조합니다. 지정한 접두사가 일치하는 경로에만 적용됩니다.

OPT 연결 키는 Begin Bates이며 없으면 Document ID입니다. Parent ID는 존재 여부, 자기 참조, 순환 참조를 검사합니다. 단순 숫자 Bates 범위의 중첩도 검사합니다. 날짜·시간대와 다른 메타데이터 값은 변환하지 않습니다.

범위와 성능

파일 100,000개, 로드 파일 500개, 논리 레코드 합계 500,000개, 저장할 상세 오류 10,000개가 상한입니다. 상한에 도달하면 정상 통과시키지 않습니다. 파일과 ID 인덱스는 메모리를 사용하므로 큰 자료는 납품 단위로 나눠 검사하세요.

기본 검사에서는 native/text/image 파일의 경로와 크기를 확인합니다. 전체 해시는 옵션이며 PDF 복구, 실제 페이지 디코딩, OCR 정확도, 악성코드 검사, Relativity import 시뮬레이션은 수행하지 않습니다. ZIP/PST 내부는 열지 않습니다.

호환 모드에서는 선택 당시 파일 목록만 검사할 수 있으므로 결과는 최소 REVIEW입니다. 기본 폴더 모드는 검사 종료 시 목록·크기·수정 시간을 다시 읽습니다. 어떤 모드도 폴더를 잠그지 않으므로 검사 중 외부에서 파일을 변경하지 마세요.

보고서

JSON에는 실행 시작·종료 시각, 설정, 파일 목록, SHA-256 지문, 검사 범위, 오류의 원래 값이 저장됩니다. CSV는 Excel 수식 실행을 막기 위해 위험한 셀에 작은따옴표를 붙일 수 있습니다. 정확한 원문 확인에는 JSON을 사용하세요.

앱은 검사 데이터를 브라우저 저장소에 남기지 않습니다. 새로고침하거나 닫으면 결과가 사라지므로 필요한 보고서를 먼저 저장하세요.
