BegAttach groups a family. Use this mode only when BegAttach equals the actual parent's Begin Bates. If the true parent was withheld or the group starts with a child, choose an explicit parent field. EndAttach is a family range boundary; it does not enumerate child documents.

4 · Check & save

Large files use a 1 MiB stream and a temporary IndexedDB disk index. No document-count or file-size cap. Individual source records: 32 Mi characters; fields: 2,000; IDs: 4,096 characters. Temporary storage quota failures stop processing.

Use a normal Chrome or Edge profile for multi-GB files. Incognito / InPrivate storage is outside the large-data validation scope. Always choose a new filename in the save dialog; confirming replacement can affect an existing file before the tool receives its handle. Saved content and the source are re-read completely; every output field is checked before PASS. The download fallback is limited to 64 MiB and requires re-selecting the saved file.
