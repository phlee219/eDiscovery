CFDI XML Viewer

Local only · no upload · values kept exactly as text
Open XML folder reads every .xml file directly inside the chosen folder (subfolders are not read) and writes each result as XML file name.xlsx beside it. Existing files are never replaced; a new name such as name_2.xlsx is used. Or drop XML files / folders here. Files are read in this browser only. Non-.xml files are skipped and counted.
Files (load order)
No files loaded.
Field names are the XML attribute names. Every value is shown exactly as stored in the file.
Select a file.
Documents: one row per XML (elements that occur once per document). Other tables: one row per repeated element (for example each Concepto or tax line). Item shows the exact position in the XML. A blank cell means the attribute is not in that XML; attributes present with an empty value are listed under Exceptions.
Errors stop a file from being parsed (it is still listed and counted). Review items are facts to check; they do not change any value.

One Excel workbook per XML (individual files)

Each workbook holds only that XML's data and is named after it (invoice.xml → invoice.xlsx). After Open XML folder they are written into that folder; otherwise you choose a destination folder once. Existing files are never replaced.

Combined Excel workbook (all loaded files)

Every cell is written as text, so codes such as FormaPago 03, ClaveProdServ 01010101, CodigoPostal 06600, 20-digit NoCertificado and amounts such as 1160.00 stay exactly as in the XML. Sheets: Documents, one sheet per repeated element type, All fields (every attribute, text and comment, one row each, including namespace declarations), Files (SHA-256), Exceptions, About.

Single table as Concordance DAT or CSV

DAT: þ qualifier, DC4 (¶) separator, UTF-8 with BOM, CRLF. CSV: UTF-8 with BOM, all values quoted, never altered. Opening a CSV by double-click in Excel converts 03 to 3; use the XLSX workbook for Excel review.
